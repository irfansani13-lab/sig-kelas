Kebijakan Privasi — SIG Kelas

Terakhir diperbarui: 22 November 2026

SIG Kelas adalah aplikasi Sistem Informasi Geografis sederhana untuk pembelajaran geografi. Dokumen ini menjelaskan data apa yang dipakai aplikasi.

1. Data yang Anda buat

Peta (gambar), titik referensi, objek digitasi, logo, dan pengaturan layout disimpan hanya di perangkat Anda (penyimpanan lokal aplikasi). Kami tidak mengunggah, membaca, atau menyimpan data tersebut di server kami. File hasil ekspor (PNG/JPEG/PDF/GeoJSON/proyek) disimpan di folder Download perangkat Anda atas perintah Anda.

2. Izin aplikasi

Aplikasi memakai izin Internet dan status jaringan untuk memuat aplikasi dan menampilkan iklan. Aplikasi tidak meminta akses kamera, lokasi, kontak, atau mikrofon. File dipilih lewat pemilih file sistem Android.

3. Iklan pihak ketiga

Aplikasi menampilkan iklan dari jaringan iklan Monetag. Jaringan iklan dapat memakai pengenal iklan perangkat, cookie, atau teknologi serupa untuk menayangkan dan mengukur iklan. Pengelolaan data tersebut tunduk pada kebijakan privasi Monetag (monetag.com). Kami tidak mengendalikan konten iklan tertentu.

4. Anak-anak

Aplikasi dimaksudkan untuk kegiatan belajar di bawah bimbingan guru atau orang tua. Kami tidak dengan sengaja mengumpulkan data pribadi anak.

5. Perubahan

Kebijakan ini dapat diperbarui sewaktu-waktu; tanggal pembaruan tertera di atas.
